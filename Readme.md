# Challenge Automation Crowdar

Este repositorio contiene las pruebas automatizadas para SauceDemo y la API de Mercado Libre utilizando el framework Playwright.

## Requisitos previos
- Node.js instalado

## Instalación
Ejecutar el siguiente comando para instalar las dependencias y los navegadores:
`npm install`
`npx playwright install`

## Ejecución de pruebas
Para correr las pruebas en Chrome y Firefox:
`npx playwright test`

## Ver Reporte y captura de pantalla de prueba fallida
Para visualizar el reporte HTML con los resultados y las evidencias:
`npx playwright show-report`
